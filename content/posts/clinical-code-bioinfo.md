# 临床、代码与生信之间的连接

我目前的主线仍然是临床医学训练，但在学习过程中，越来越能感受到科研问题、数据分析和工具开发之间的连接。

## 我关注的方向

- 从临床问题出发，理解疾病机制和研究设计。
- 用代码处理重复任务，让分析流程更稳定、可复现。
- 通过生信方法把公共数据、实验数据和文献线索连接起来。

这些兴趣并不是彼此分离的技能树。对我来说，它们更像是同一件事的不同侧面：如何把一个医学问题拆开、验证、表达，并持续改进。

```text
clinical question -> data -> analysis -> tool -> note
```

这个 blog 会作为一个记录场，保存这些过程中的小结和迭代。
